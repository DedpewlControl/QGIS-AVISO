# French vACC QGIS AVISO Project

Welcome to the official collaborative repository for the **French QGIS AVISO Project**.

This repository is designed to support **collaboration, maintenance, and issue tracking** for the French vACC AVISO database. It contains the **structure and configuration files** that make up each AVISO, ensuring consistency, realism, and compatibility for controllers.

---

> ⚠️ **Important:**  
> This repository does **not** contain the converted, ready-to-use AVISO files (such as `.sct` and `.ese` files).
>
> The AVISOs in this repository are automatically included in the French vACC Controller Pack & Sector File every 28 days, in accordance with the AIRAC cycle dates.
